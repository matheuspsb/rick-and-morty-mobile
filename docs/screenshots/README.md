## Como recapturar

Local padrão no Windows: `C:\Users\<user>\OneDrive\Imagens\Screenshots` (ou a Área de
Trabalho) — botão de câmera na barra do emulador. Alternativa CLI com o app rodando:
`flutter screenshot` ou `adb exec-out screencap -p > 04-results.png`. Renomeie conforme
a tabela.
